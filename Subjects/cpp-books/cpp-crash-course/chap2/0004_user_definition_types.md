# Que tipos são esses?

Bem, são jtipos que os usuários podem ser definidos pelos usuários. Dentre eles:
Enumeration - A mais simples dos tipos definidos pelo usuário. Os valores de uma enumeração podem ser restringido para um conjunto definido de possíveis valores. Excelentes para modelar conceitos de categoria.
Classes - As estruturas mais flexiveis, classes podem conter informação e métodos. Classes que contém apenas informação são chamadas baseadas em informação.
Uniões - Tipo em que todos os membros compartilham o mesmo local de memória. São estruturas perigosas.
